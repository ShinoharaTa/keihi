# keihi: MF / freee 個人プランの比較と移行判断（ドラフト / 2026-10-13）

目的: 「今の MF プランで keihi（API 連携）が作れるか」「freee に移るべきか」をユーザーが判断できるようにする。
表記: 【事実】= 公式ページで確認（出典番号つき）、【推測】= 筆者の解釈、【要確認】= 実機・問い合わせで確かめる。
価格は特記がない限り税抜。税込は ×1.1 で筆者が計算した。

---

## 0. 結論（先に読む）

1. **MF のパーソナルミニで API が使えないという記載は、公式にはどこにも無い。**
   - 【事実】API の対象は「クラウド会計・確定申告をご利用中のお客さま」。追加料金は無い。プランの制限として書かれているのは「登録できる仕訳の件数などは有償プランの制限と同じ」だけ [M3][M4]。
   - 【事実】プラン別機能表（2026-06-18 更新）にも API の行は無い。「表に無い機能はプランに関係なく使える」とある [M2]。表にある「外部サービス」の行は MAP3 向けの CSV 出力のことで、API とは関係ない [M8]。
   - 【要確認】実際に動くかは PoC で確かめる。費用はかからない（API キーを発行し、GET を 1 回、証憑の POST を 1 回試す）。
   - **例外**: 契約が「パーソナルミニ **アプリプラン**」（iOS/Android のアプリ内課金、月 1,500 円税込）の場合は、クラウドBox の「ファイル」画面からアップロードできず、確定申告以外の有償機能も使えない [M2][M6]。年 10,800 円（税抜）は Web 版パーソナルミニの年払いと一致するので、ユーザーの契約はおそらく Web 版【推測】。
2. **Mini で本当に制約になるのは API ではなく、証憑の件数。** クラウドBox に保存できるのは**累計 1,000 件まで**で [M6][M7]、API で上げた証憑も Box に入る [M9]。月 30 枚なら約 2.8 年で上限に達する【推測】。7 年分は入らない。
3. **freee のスタータープランは keihi には使えない。** ファイルボックスへのアップロードが**月 5 枚まで**（PC からのアップロードなども含む）で [F1][F2]、API の receipts にもプランごとの上限がかかる [F4]。freee に移るならスタンダード（年 23,760 円）が最低ライン。
4. **推薦: MF に残る。** まず Mini のまま API を PoC で試し、証憑が 1,000 件に近づいたらパーソナル（年 22,560 円）に上げる。freee スタンダード（年 23,760 円）とは年 1,200 円しか差が無い。それなら移行の手間と、過去分が 2 か所に分かれるリスクを負う理由が無い。
   freee に移るのは、MF の PoC で致命的な問題（Mini で API が拒否される、API で上げた証憑をスキャナ保存の区分にできない、など）が見つかった場合に限る。その場合も**切り替えは 2027-01-01**（理由は §4.2）。

## 1. MF クラウド確定申告（個人）

### 1.1 料金（税抜。2026-12-01 改定後。既存の契約は、改定日以後の更新日から新料金）[M1][M5]

| プラン | 年払い（現行 → 改定後） | 月払い（現行 → 改定後） |
|---|---|---|
| パーソナルミニ | 10,800 → **10,800（据え置き）**（税込 11,880） | 1,280 → 1,680 |
| パーソナルミニ アプリプラン | — | 1,500 → 1,880（**税込**） |
| パーソナル | 15,360 → **22,560**（税込 24,816） | 1,680 → 2,880 |
| パーソナルプラス | 35,760 → **38,160**（税込 41,976） | 設定なし |

- 【事実】改定の適用は契約の更新時から。例: 2026-11-15 に年払いを契約した場合、新料金は 2027-11-15 の更新から [M5]。
- 【事実】AI-OCR の従量課金（パーソナルは月 31 件目から、プラスは月 101 件目から 20 円/件）は 2026-12-01 に廃止され、無制限になる。Mini は月 15 枚のまま [M5]。
- 【事実】プランの追加・廃止の告知は無い [M5]。
- 【事実】年払いを途中で解約しても、料金は満額かかる。返金や日割りは無い [M10]。「解約操作は即時に反映され、残りの期間は無効になる」という記載は検索結果の要約で見ただけで、本文は未精読【要確認】。

### 1.2 機能（プラン別機能表、2026-06-18 更新）[M2]

| 項目 | ミニ | パーソナル | プラス |
|---|---|---|---|
| 確定申告書のプレビュー、PDF 出力、xtx 出力、スマホからの提出（e-Tax） | ○ | ○ | ○ |
| 青色申告決算書の作成 | ○（表に行が無い＝全プランで使える）【事実: 表の注記】 | ○ | ○ |
| 消費税申告 / 課税事業者の設定 | ✗ | ○ | ○ |
| 仕訳登録の件数 | 10 万件/年 | 10 万件/年 | 10 万件/年 |
| 証憑添付機能（保存先はクラウドBox） | **1,000 件まで** | 無制限 | 無制限 |
| ストレージ容量 | **100MB** | 10GB | 10GB |
| 仕訳帳・総勘定元帳などの CSV 出力 | **✗** | ○ | ○ |
| AI-OCR | 15 枚/月 | 無制限 | 無制限 |
| メンバーの追加 | ✗ | ○ | ○ |
| API（会計・確定申告 API v3） | 表に行が無い（＝制限の記載なし） | 同左 | 同左 |

- 【事実】クラウドBox: 無償の状態ではアップロードできない。Mini は**累計 1,000 件**まで。それを超えるにはアップグレードが要る。従量課金は無い [M6]。
- 【事実】ストレージ（100MB）の対象は、帳簿の PDF/CSV、手動アップロード、経費の画像など [M11]。**クラウドBox の証憑が 100MB に含まれるかは書かれていない**【要確認】。
- 【事実】スキャナ保存は事業者設定でオンにする。証憑添付は「有償契約の事業者のみ」で、プランの区別は無い [M9][M12]。
- 【事実】優良な電子帳簿は「仕訳履歴保存機能」をオンにし、届出を出して対応する。プランの制限は書かれていない（2026-09-04 更新）[M13]。
- 【事実】JIIMA 認証: 「クラウド確定申告 + クラウドBox」がスキャナ保存の認証を持つ（期限 2028-03-27）。電子取引・電子帳簿の認証もある（docs/legal.md §2.1）。

### 1.3 API と「全権管理」
- 【事実】アプリポータルを使い始めるには、管理コンソールの「全権管理」権限が要る。API キーを作るときは、利用可能サービスとして「事業者情報」と「クラウド会計・確定申告」にチェックを入れる [M3]。
- 【事実】API キーには有効期限が無い（交換して得る JWT は 1 時間）。プラン・権限の区別による発行制限は書かれていない [M14]。
- 【事実】2024-09 以降、会計・確定申告の利用開始は「オーナー」（＝事業者を作成したアカウント）か、管理コンソールの「全権管理」権限を持つユーザーができる [M15]。
- 【推測】個人で自分が事業者を作ったなら、自分が全権管理を持っている可能性が高い。確認方法: 管理コンソール →「ユーザー」画面で自分の権限を見る。
- 【事実】技術サポートは、有償の公認メンバーである士業事務所に限られる [M3][M4]。

### 1.4 解約後
- 【事実】仕訳は削除されず、ログインすれば見られる。ただし 50 件を超える登録と、CSV エクスポートはできない [M16]。
- 【事実】Box のファイルは、解約後も電帳法の要件を満たしたまま保存される。閲覧・検索・ダウンロードもできる。制限がかかるのはアップロードだけ [M6][M17]。

- 【事実】アプリ内課金だと税込でスターター 12,800、スタンダード 26,800、プレミアム 44,800（年払い）[F2]。

| 項目 | スターター | スタンダード | プレミアム |
|---|---|---|---|
| API（Public API） | ○ 全プラン [F3] | ○ | ○ |
| 1 日の API コール上限（事業所・アプリごと） | 3,000 [F4] | 3,000 | 3,000 |
| ファイルボックスへのアップロード | **月 5 枚**（API も含む）[F2][F4][F5] | 月 10GB | 月 10GB |
| 電子帳簿保存機能 | ○ [F2] | ○ | ○ |
| 優良な電子帳簿 | ○ [F6] | ○ | ○ |
| 確定申告書・青色申告決算書 | ○ [F2] | ○ | ○ |
| e-Tax 送信 | ○ 全プラン [F1] | ○ | ○ |
| 消費税申告 | ✗ | ○ | ○ |

- 【事実】receipts API の制限: 1 ファイル 64MB、月 10GB、1 分あたり 300 ファイル。加えて「プランによる月間アップロード数の制限」がかかる [F4]。
- 【事実】Web 版で使える機能は API でも使える。例外は総勘定元帳 API と固定資産台帳 API で、どちらも法人の上位プラン限定 [F4]。
- 【事実】JIIMA のスキャナ保存認証の期限は **2027-10-15**（docs/legal.md §2.1）。更新されるか【要確認】。

### 2.3 解約後（プラン未契約の状態）[F2][F5]
- 【事実】取引データの閲覧・編集、仕訳帳・総勘定元帳の CSV/PDF 出力ができない。Public API による連携は停止する。
- 【事実】ファイルボックスの閲覧と保管はできる（アップロードは月 5 枚まで）。
- 【事実】紙の原本を廃棄した場合、法定の保存期間中はアカウントと事業所を削除せず、ファイルボックス上で保存すること。ダウンロードしたファイルだけでは要件を満たさない。
- 【推測】freee を解約すると帳簿が見られなくなる。そのため freee に入ったら、保存期間中は有償契約を続けるのが前提になる。MF より縛りが強い。

## 4. 移行する場合の注意（B 案を選ぶとき）

### 4.1 MF 側に何を残すか
- 【事実】MF は解約して無償状態になっても、Box の証憑は要件を満たしたまま保存され、閲覧・検索・ダウンロードができる [M6][M17]。仕訳も見られる [M16]。→ **証憑の 7 年保存のために MF の有償プランを残す必要は無い**。ただし事業者とアカウントは削除しない。
- 【推測・要税理士確認】無償状態では帳簿の CSV が出せない。電子帳簿の保存要件「税務職員からダウンロードを求められたら応じる」を満たせるか不明。**Mini も CSV 出力は ✗ なので、今の時点で同じ問題を抱えている可能性がある**。仕訳帳を PDF で出力できるかを確かめる（Mini の表に PDF の行は無い）。

### 4.2 年の途中で移らない
- 【事実】75 万円控除（令和 9 年分から）を受けるには、仕訳帳と総勘定元帳を、その年の**最初から**優良な電子帳簿で保存する必要がある（docs/legal.md §3）。
- 【推測】年の途中で移行すると、1 年分の帳簿が 2 つのソフトに分かれる。優良帳簿の「年の最初から」の要件と、訂正削除の履歴の連続性が崩れる。→ **切り替えるなら 2027-01-01**。2026 年分の申告は MF で 2027-03-15 までに出す。
- 【事実】MF の年払いは途中で解約しても返金が無い [M10]。更新日が 2027-03-15 より前なら、2026 年分の申告のために 1 回更新する（ミニの年払いは改定後も 10,800 円）か、月払いで繋ぐ（改定後 1,680 円/月）。**ユーザーの更新日は未確認。**

## 5. 推薦
**A 案（MF に残る）。ミニで始め、証憑が累計 800〜900 件になったらパーソナルに上げる。**
- 理由 1: パーソナル（22,560）と freee スタンダード（23,760）の差は年 1,200 円しかない。費用は移行の理由にならない。
- 理由 2: MF は解約後も仕訳と証憑が見られる。freee は帳簿が見られなくなる。7 年保存の縛りは MF の方が緩い。
- 理由 3: 2026 年以前の証憑と帳簿は MF にある。移らなければ、保存場所が 1 つで済む。
- 代償: API の実装は freee より面倒（仕訳を先に作る、5MB、メタデータを渡せない、削除できない）。architecture.md §1.2 で設計に織り込み済み。
- 撤退条件: PoC で次のどれかが起きたら B 案に切り替える（2027-01-01 から）。
  ① ミニでも、パーソナルに上げても API が拒否される
  ② API で上げた証憑を「スキャナ保存」として扱えず、UI でも修正できない
  ③ タイムスタンプも履歴も付かない

## 6. 決定事項 / 未決事項

決定済み（本調査による事実）:
- MF の公式情報に、プランによる API の制限は無い。
- freee スターターは月 5 枚のため、keihi には使えない。

未決（担当）:
1. ユーザーの契約が Web 版ミニか、アプリプランか。更新日はいつか → **ユーザー**（MF の「料金・プラン管理」画面で確認）
2. 全権管理を持っているか → **ユーザー**（管理コンソール → ユーザー）
3. 今の Box の証憑件数と、月あたりの証憑の枚数 → **ユーザー**
4. ミニで API キーを発行し、証憑を POST できるか（区分、タイムスタンプ、1,000 件の数え方）→ **implementer**（PoC。テスト用の事業者を作るのが安全）
5. Box の証憑がストレージ 100MB に含まれるか → **implementer**（PoC）または MF サポート
6. ミニ（CSV 出力 ✗）で、電子帳簿のダウンロード要件を満たせるか → **税理士**
7. 更新日より前にパーソナルへ上げた場合、旧料金（15,360）で 1 年契約できるか → **MF サポート**（ユーザーが問い合わせる）
