# 保持期間（docs/legal.md §1.5・§2.4、architecture.md §3.4、R18）

**下書き。起算日と期間は税理士確認 #8 の答えで確定する。**

## 1. 方針

- 法定の保存は freee のファイルボックス（と freee の帳簿）。保存期間中は freee の有償契約と事業所を残す（freee-codex.md §2.5）。
- keihi 側（原本・DB・バックアップ）は控え。ただし種類を区別せず、**一律に長い方（7 年）+ 余裕 1 年 = 8 年**を保持する。
- 期間を過ぎても**自動では消さない**。一覧に出し、人が判断して消す（削除の仕組みは今は作っていない。必要になったら別タスク）。

## 2. 法定の期間（個人・青色。legal.md §1.5）

| 種類 | 期間 |
|---|---|
| 帳簿 | 7 年 |
| 決算関係書類 | 7 年 [要確認] |
| 現金預金取引等関係書類（領収書など） | 7 年（前々年分の所得が 300 万円以下なら 5 年） |
| その他の書類（請求書・見積書・契約書・納品書など） | 5 年 |
| 消費税の課税事業者: 仕入税額控除のための請求書等 | 7 年 |

電子データ（スキャナ保存・電子取引）も同じ期間（スキャナ 問9、電子取引 問17）。

## 3. 起算日

- 帳簿: 閉鎖日の属する年の翌年 3/15 の翌日（= 翌年 3/16）から。
- 書類: 作成・受領日の属する年の翌年 3/15 の翌日（= 翌年 3/16）から。
- keihi では一律に「**受領日（documents.received_on）の年分の翌年 3/16** から 8 年」とする。
  例: 2027-05-10 に受領 → 起算日 2028-03-16 → keihi 側の保持期限 2036-03-15（法定の 7 年は 2035-03-15 まで）。

設定として持つ予定のキー（`src/config.ts` に未統合。今は使っているコードが無い）:

```toml
[retention]
years = 7          # 法定の期間（一律。税理士確認 #8 で 5 年の特例を使うなら書類の種類ごとに分ける）
extra_years = 1    # 余裕
start = "next_year_0316"   # 起算日の規則。受領日の年分の翌年 3/16
```

## 4. 各保存先の扱い

| 保存先 | 保持 | 消すもの |
|---|---|---|
| keihi の原本（`objects/`） | 8 年以上。上書き・削除の API なし（0444） | 消さない（期限後に人が判断） |
| keihi の DB（documents・audit_log 等） | 8 年以上。追記専用の表はトリガで削除を拒否 | 消さない |
| DB のスナップショット（`snapshots/`） | 直近 `keep_snapshots` 個（既定 7） | 古いものは run.ts が消す（原本ではない。restic 側に残る） |
| restic（オフサイト） | 追記のみ。prune / forget をしない | 消さない |
| B2 の Object Lock（Q4） | governance・8 年 | 保持期間中は鍵の権限でも消せない |
| freee のファイルボックス | 法定の保存。7 年以上 | keihi からは消さない（`DELETE /receipts` を使わない） |
| リストア訓練の復元先（`drill/`） | 成功したら消す。失敗したら調べ終わるまで | 手で消す |

## 5. 年次の書き出し（R19）

解約や障害に備え、年分ごとに freee から証憑と仕訳を書き出す（法定の保存はアカウント側。書き出したファイル単体では
要件を満たさない。legal.md §2.3）。手順は [procedures.md](procedures.md) §5。書き出したものは keihi の原本と別の場所
（例: 外付けディスク）に置く。

## 6. 見直しの時期

- 2027-03（2026 年分の申告後）: 税理士確認 #8 の答えで §2・§3 を確定。
- 2027-10: freee の JIIMA 認証（スキャナ保存は 2027-10-15 まで）の更新を確認。
- 毎年 3/16: 起算日を過ぎた年分を確認（期限はまだ先なので、確認だけ）。
